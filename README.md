# MultiCalc - Multipurpose Calculator

MultiCalc is a modern, responsive, and professional multi-purpose calculator web application built with HTML5, CSS3, and Vanilla JavaScript. 

## Features
- **Modern UI**: Clean, responsive layout with dark/light mode and smooth transitions.
- **20+ Calculators**: Includes Basic, Scientific, Age, BMI, EMI, Discount, GST, Unit Conversion, Percentage, Fraction, Ratio, and many more.
- **No External Dependencies**: Built entirely with vanilla web technologies, without any frameworks or libraries. No eval() used for parsing math expressions.
- **Favorites & Recents**: Easily access your most used calculators.
- **Calculation History**: Keep track of your past calculations, saved securely in `localStorage`.
- **Keyboard Support**: Full keyboard input support for Basic and Scientific calculators.

## How to Run
Simply open `index.html` in your web browser. No local server or build step is required!

```bash
# Example if you want to use a local server
npx serve .
```

## Structure
- `index.html`: The main document structure and layout.
- `style.css`: All styling, themes, and responsive design queries.
- `script.js`: Contains all the calculator logic, UI binding, and custom math parser.

Enjoy calculating!
